# ETF轮动

独立入口 `/etf-rotation`，由前后端源码扩展注册。支持复合动量、黄金避险、跨境轮动；配置、任务、行情快照和结果保存在用户数据目录的 `etf_rotation/` 下。

## 使用

1. 选择策略模板，通过代码或名称搜索ETF，修改候选池及参数。黄金避险的避险ETF和参考ETF单独设置。
2. 保存命名配置，设置区间、初始资金、佣金及滑点。所有收益阈值均为小数，例如 `0.03` 代表3%。ETF印花税为0。
3. 检查数据覆盖。预热不足时，显式确认共同可用起点再重新检查；缺行情时可点击“准备所选标的数据”。该操作会调用系统现有同步服务补齐所选ETF、复权因子及沪深300参考日线，不更改核心指数展示列表或全局数据源设置。沪深300优先使用当前日线源；其请求失败或无数据时，单次任务回退到 TickFlow，并在任务结果中标明实际来源。
4. 开始回测，在结果页查看进度、取消任务、查看历史结果、每日全部持仓及排名、因子原值与截面Z-Score、成交和费用，导出CSV。
5. 决策预览默认只评估空仓开仓机会。勾选回测上下文后，使用该回测期末状态推演到最新完整收盘日；配置必须相同，行情复权发生变化时要求重新回测。预览不会写入任何模拟账户。

## 计算口径

- 每日先执行前一收盘生成的指令，再收盘估值和决策。结束日指令作为待执行项保留，不制造期末卖出。
- 因子、成交和估值使用当前系统前复权OHLC，属于复权价研究回放。整手为100份；佣金、最低佣金和滑点进入统一FIFO账本。真实分红、份额变化、盘口排队和盘中精确成交不在此模型内。
- 原始价格用于成交限制。日线停牌、零成交量、开盘价缺失不成交；原始高低价相同的单一价日保守不成交，不套用股票代码规则推断ETF涨跌停幅度；保留在途退出或换仓。缺行情的持仓沿用上次有效估值，并逐日标记，不补造成交价。
- 全池和参考数据就绪后开始；中间缺口期间暂停新决策，不删除某只ETF来改变截面。等权基准为所选候选池在同一起点买入持有，期间不再均衡；基准缺日行情沿用上一有效估值。
- 黄金正常换仓和避险切换一次完成；复合动量默认3步，跨境轮动默认5步。渐进计划锁定目标，风险退出优先并中断计划。目标ETF持有期从首笔实际买入开始计算。
- 单标的风控B为浮动止盈与ATR止损；账户15%回撤保护有独立开关。风险退出清仓后以当前现金重置账户高水位，当天不生成重新买入指令，后续收盘重新评估。
- 最新收盘日使用北京时间15:10之后的已落盘数据；接口会拒绝尚未完整收盘的结束日期。数据仍旧时预览明确显示实际行情日期。

## 原项目对应与修正

公式依据 `etf-daily-sync-and-backtest` 源版本 `586bf3737261866337952fc0ead53b1f77081be0` 重新实现；运行时不导入该项目，不访问它的SQLite文件，也不复用其全局变量配置。

- 复合动量：四因子各25%，趋势5/20/60日权重15/50/35%；20日Sharpe使用总体标准差，截面Z-Score使用样本标准差；量价为 `(量比-1)×收益方向`。沪深300MA60状态倍率保留为牛市1.1、熊市0.8，不能将其解释为仓位缩减。
- 黄金避险：硬阈值三条件采用正常池最差5日收益、21/63日波动率比及下跌广度。参考ETF默认510300，使用精确60日均线，缺数据暂停判断，不再默认牛市。参考ETF即使不在正常池中也会加载。
- 跨境轮动：10日动量，2%最低切换差，保留使用已知成交额估算的摩擦门槛。冲击估计只进入切换门槛，不在账本额外重复扣费。
- 修正原引擎用当日高低收盘触发风控却按当日开盘成交、部分调仓绕过批次账本、虚拟平仓和持有期统计的问题。改为逐持仓批次追踪风控，优先清理全部在途仓位。

这些修正及系统数据源、复权口径的差异会改变收益。原项目README的收益数字不是此模块的验收标准。

## 隔离、存储及任务

API独立前缀 `/api/etf-rotation`，包含 `strategies`、`configs`、`data-check`、`data-prepare`、`backtests`、`preview`。任务列表同时显示数据准备和回测任务；配置更新带revision，冲突返回409。历史任务保存配置和数据快照、SHA-256摘要、算法及源版本；编辑或删除配置不修改历史结果。

轮动模块拥有单独队列，最多一个任务运行，其余排队；计算在spawn子进程执行。队列使用文件锁避免多个后端进程共同管理同一个目录；当前应使用单后端工作进程。取消后终止计算子进程；数据同步在当前网络调用返回后响应取消。重启将未完成任务标记为中断，不自动重放。

已有回测引擎、策略注册、结果存储和任务调度未接入本模块。前端仅扩展共享API方法、查询键并复用图表生命周期Hook，后端复用仓库和数据同步边界。

## 验证

后端定向测试位于 `backend/tests/etf_rotation/`，覆盖三策略公式、无未来数据、FIFO成本守恒、资金不足、渐进调仓、风险退出、数据缺口、预览延续、CSV、任务取消、进程隔离和重启。前端测试覆盖扩展注册冲突、参数重置、ETF池编辑后数据预检失效及预览失败状态。

页面验收使用独立临时数据目录中的固定合成样本，不代表策略收益。真实行情源的权限、完整历史及收益需要在用户选定的数据源上另行执行数据准备和回测。

## 环境增强版本（rotation-v2）

模板新增“复合动量·环境增强”。它沿用基础复合动量评分及普通轮动规则，并在每次收盘按沪深300相对均线偏离生成目标仓位：默认MA60、±2%区间，牛市100%、震荡50%、熊市0%；均线周期、偏离阈值与三个仓位可配置，须满足熊市≤震荡≤牛市。实际开盘调整时另留2%现金及整手余量，之后价格变化会使实际仓位偏离目标。

环境调仓优先于普通最小持有期限制，风控退出优先于环境调仓。非零仓位变化只调整现有持仓，不借机改选另一只ETF；有在途渐进换仓时暂停一步，缩放现有组合后继续原锁定目标。熊市目标0时退出全部持仓、取消原计划；退出失败保留待执行指令。所有环境指令都在下一交易日开盘执行。

每次增强版回测自动用同一份行情快照、起止日期、费用和风控参数重放基础复合动量，结果页并列显示收益、回撤、夏普、平均实际仓位及净值曲线。该基础对照使用完整历史预热和已修正的执行引擎，不是原项目历史截图的复刻。环境增强是实验性选项，基础模板保持默认，不承诺提升收益。

每日排名和预览现在展示轮动环境依据：沪深300收盘、均线、偏离幅度、判断区间、评分倍率以及是否控制仓位。系统原有“市场环境”模块综合赚钱效应、投机、抗跌与趋势，分强势/偏强/震荡/偏弱/弱势；此处只读取同日已存储的state/score作旁证，不读取未来日期，不把情绪周期的事后阶段标签用于交易。没有该日综合数据会明确显示缺失，轮动仍可使用自己的指数均线判断。

算法版本更新为rotation-v2。已有结果仍可查看和导出；旧版本状态不能直接续算为新版本预览，需重新回测，不覆盖旧快照。数据摘要现在包含综合环境参考快照。
