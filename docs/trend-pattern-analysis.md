# 趋势与经典形态分析

“指标分析”页签改为消费 `stock-trend-pattern` 的原生 Python 移植结果，股票、ETF、指数共用分析契约。行情来自当前图表已经取得的快照，不新增行情源、Node 服务或磁盘数据。原 technical-score API 保留，供现有其他消费者使用。

## 接口

`POST /api/stock-analysis/trend-patterns`

```json
{
  "symbol": "512000.SH",
  "period": "1d",
  "as_of": "2026-10-29",
  "n": 250,
  "tail": 160,
  "rows": [
    {"date": "2026-10-29", "open": 0.474, "high": 0.474, "low": 0.464,
     "close": 0.465, "volume": 100, "is_closed": true}
  ]
}
```

该接口对请求提供的 OHLCV 做分析，不自行按代码取数。页面传入标准化的图表快照，因此与当前展示的资产、周期、观察日期和复权口径一致。外部调用者应提供相同口径的已收盘行情，不能把原始价与复权价拼接。

`rows` 最多1500根，必须按北京时间墙钟严格递增，无重复。周期支持 `1d/1w/1mo/30m`。`is_closed` 必填；未收盘K线和 `period_end` 晚于观察时间的K线排除。先按观察时间截断，再计算指标与形态。`n` 为最近实际K线根数（30～1500，默认250），`tail` 为回传根数（1～1500，默认160）。样本不足30根时返回 `status=insufficient` 和空方向判断，不伪装为震荡。

始终返回以下七个字段：

| 字段 | 内容 |
| --- | --- |
| `candles` | `[日期, 开, 高, 低, 收, 成交量]`，成交量缺失时为 null |
| `indicators` | MA、MACD、RSI、KDJ、BOLL、OBV、成交量均线，与 candles 对齐 |
| `trend` | 20/60/120根三级趋势、参与判断的高低点价格，窗口不足时 unknown |
| `swings` | 高点 ph、低点 pl，发生日期、确认日期和相对 candles 的位置 |
| `levels` | 支撑/阻力、触碰次数、最近日期、距现价百分比，按距离排序 |
| `patterns` | 最多9个形态，包含匹配度、形成/确认状态、确认时间、真实结构价位与量能依据 |
| `verdict` | 综合方向、形态/均线/趋势分、是否同向、5/20量比、最近支撑阻力和空间比 |

形态 `at` 是确认或观察K线在 `candles` 中的位置，`anchorAt` 是结构锚点位置；不在回传窗口内时为 null。支撑阻力 `lastIdx` 同理。摆动点同时返回 `i` 和 `confirmedIndex`，不能在发生日期提前使用右侧尚未确认的信息。

几何形态的 `confirmedAt` 是本次快照能够确认该结构的观察截面，不追溯为最早交易信号日期；不能将该字段直接当作策略回测成交时间。

`GET /api/stock-analysis/pattern-catalog` 返回84个教学条目，页面仅在打开形态库/图解时加载。教学中的价格只供图解使用，不进入诊断的 buy/sell/stop/target。

## 移植与调整

上游为 [CrabOctopus/stock-trend-pattern](https://github.com/CrabOctopus/stock-trend-pattern)，固定提交 `53d1945f373e8bb617c5cb2884518509b76e0d50`。MIT 许可证及原始目录保存在 `backend/app/services/trend_patterns/`。

- 将识别规则移植为 Python；MA/MACD/RSI/KDJ/BOLL 复用现有指标流水线，数值可能与上游的初始化、标准差口径不同。OBV 和成交量均线用 Polars 计算。平盘 RSI 展示为50；缺量不伪造零成交量或量能确认。
- 修正双底/头肩底错误使用高点、蜡烛图从旧到新扫描、短影线阈值方向、123回踩条件恒真等问题；补充原库缺少检测规则的上升/下降三法。
- 区分形成中与已确认，只有已确认形态参与形态方向分。规则匹配度不是统计胜率；组合形态是价格模式，并不等于交易触发。
- 实际结构生成触发、失效和测量目标价；缺乏依据时目标为空。禁止按教学价格等比缩放。
- 保留原综合评分结构：形态分限幅±10，均线分按排列与MA20位置计分，趋势分按长期2/中期1.6/短期1.2加权；三项同向才允许强方向结论。盈亏比仅为最近阻力空间/最近支撑距离，缺一侧则为null。
- 形态算法为启发式规则，尚未完成市场胜率校准或策略绩效验证。20/60/120均为当前周期K线根数，不声称周线和30分钟已经过相同的市场参数校准。

## 缓存和兼容

前端查询键包含版本、标的、资产类型、周期、观察时间和实际OHLCV/收盘状态。行情内容或历史日期变化后重新计算，不使用上一标的的结果。服务只缓存不可变教学目录，分析本身无额外结果缓存，不写仓库、策略、enriched、用户画线或数据库。

本次属于L3：直接替换既有指标面板，并在现有分析路由增加纯计算接口。旧策略评分和其他分析页签保持原契约；以后升级上游时需复核 Python 规则、目录结构和接口类型，不能直接覆盖移植代码。

## 命中形态绘制

点击命中卡片标题，在当前主图单选显示实际识别结构，再次点击或点击“取消形态”清除。教学入口独立。切换分析页签保留绘制；标的、周期、观察时间或行情快照变化时清除。定位只改变图表视野，不改变分析截面。

`patterns[].geometry` 为新增可选字段：`start/end` 是绝对日期，`paths` 包含 `label` 和 `{date, price}` 点序列，`zones` 包含 `start/end/lower/upper`。坐标直接来自识别规则，与回传 candles 的 tail 索引无关；K线组合以区间内实际蜡烛高亮。形成中结构绘制虚线。已有 triggerPrice、stopPrice、targetPrice 分别标注触发价、失效价、测量目标。缺少坐标时提示刷新，图表行情不完整时只画能核对的部分并提示。

覆盖层使用独立的 `tsp-pattern` 分组，不写入用户画线或数据库。前端分析查询版本更新为 v2，后端原识别、评分与数据截断规则保持不变。

## 动量与均值回归（ammr-v1）

指标分析在原综合研判之后展示独立双评分，不计入原综合分。复用同一请求、已收盘及历史日期截断后的完整计算样本；窗口均为当前周期K线根数，至少65根。股票、ETF、指数采用相同描述规则，不包含交易执行或多周期联动。

动量分范围−100～100：ROC20、ROC5、MACD柱、RSI14、MA20近5根斜率的权重分别为30/20/20/15/15；各项标准化后截断至−1～1。ROC以`2×ATR14/close×sqrt(N)`标准化，MACD及斜率以ATR标准化，RSI以`(RSI−50)/25`标准化。≥20偏强、≤−20偏弱；近3根分数变化≥5增强、≤−5减弱。

环境按顺序判断：价格与MA20/60多头排列且斜率/ATR>0.25为上涨，反向且<-0.25为下跌；ER20≤0.3且均线距离≤ATR为震荡，否则不明确。ER为20根净变化绝对值除以逐根变化绝对值之和。

回归分范围0～100，Z沿用布林带样本标准差。在近5根选绝对Z最大且≥1.5的锚点（同值取近者），负值观察低位回升、正值观察高位回落。偏离贡献`40×clip((abs(Z锚)−1)/1.5)`，恢复贡献`35×clip((abs(Z锚)−abs(Z当前))/abs(Z锚))`，转向贡献`25×clip(方向修正后的3根动量变化/30)`，clip范围0～1。最新价格和Z必须同时向均值移动，否则总分封顶39；≥70条件较充分、40～69开始改善，其余尚待确认。穿过均值或绝对Z≤0.25后标记完成、机会分归0；无有效锚点归0。完全平价时动量0、Z为空、回归无机会；必要指标异常则为空分而非0分。

接口新增可选`momentumReversion`字段，含版本、状态、环境、双评分、依据及联合解读，随完整JSON导出。旧响应在前端显示模块暂不可用。规则分不代表概率、偏离不保证回归，参数尚未经收益校准。

### 机会判断（opportunity-v1）

双评分上方增加醒目的机会结论及原因，随`momentumReversion.opportunity`返回并导出；旧响应缺少字段时提示刷新，不在前端自行推断。评分公式不变。

- 下跌环境优先：低位回归开始且动量改善时显示“弱势反弹观察，低吸条件不足”；其余显示“下跌防守，等待止跌”，即使回归高分也不转为低吸候选。
- 回归完成后显示“本次回归已完成，等待新机会”。
- 高位回归或当前Z≥1.5且动量较3根前减弱至少5分，显示“高位回落风险，谨慎追高”；仅当前高偏离则为“短期偏热，谨慎追高”。
- 低位回归开始、成熟度≥70且动量较3根前增强≥5分：震荡环境显示“区间低吸候选”；中期结构上行（MA20>MA60、MA20近5根斜率/ATR>0.25且价格>MA60）显示“顺势回调低吸候选”。回调时价格可以低于MA20，因此不要求严格上涨环境。
- 上涨环境、动量≥20而未形成回调候选时显示“趋势延续观察，等待回调”；其余显示“等待确认，低吸条件不足”，并列出缺少的确认条件。

这些是当前周期的观察候选，未联合验证支撑、失效位置、盈亏空间或成交约束；不生成买卖订单。
