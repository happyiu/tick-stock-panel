# CZSC 缠论结构计算（契约 v4）

## 内核和数据流

现有行情仓库 → K线接口标准化、复权、周期聚合与闭合标记 → 后端 `services/chanlun.py` → 官方 CZSC Python 包的 Rust/PyO3 内核 → 前端查询、覆盖层、面板及 AI 页面快照。

固定 `czsc==1.0.2`（官方 tag `v1.0.2`，commit `5d350a943d6b1935561765fed5467c234973d121`，Apache-2.0）。依赖由 `pyproject.toml` / `uv.lock` 管理，不复制官方算法、不调用官方数据连接器、不回退 chan.py。源码：[官方 v1.0.2](https://github.com/waditu/czsc/tree/v1.0.2)。

`min_bi_len=6`，`max_bi_num=max(50, 已闭合K数)`，显式覆盖环境变量默认值。分析窗口与响应 K线相同，不偷偷添加预热历史；不同起点可能形成不同结构。支持30分钟、日、周、月；中枢采用官方 `zs_list`，要求至少三笔且 `is_valid()`，允许 ZG=ZD。趋势分类仍是本项目最近两个中枢位置近似，不是官方递归走势确认。

官方分型、笔与笔中枢仍直接映射原生输出。图层扩展采用 `chartRules.version=1`：线段在后端基于官方笔按项目特征序列推导，背驰观察调用固定官方MACD规则；趋势云带及中枢延长线为项目绘图投影。线段中枢、旧 MACD 面积背驰和旧三类信号引擎继续停用；对应兼容字段保留空数组。未增加筛选任务、通知、回测和交易。

## 官方辅助信号

| 输出 | 函数 | 固定参数 |
| --- | --- | --- |
| B1 / S1 | `cxt_first_buy_V221126` / `cxt_first_sell_V221126` | di=1 |
| B2 / S2 | `cxt_second_bs_V240524` | di=1, w=9, t=2 |
| B3 / S3 | `cxt_third_bs_V230318` | di=1, ma_type=SMA, timeperiod=34 |

逐根更新后调用官方 dispatcher，只记录实际命中，返回函数、参数和官方原始 key/value。B2是官方分型价格密集区辅助规则，不要求先出现B1；B3包含均线条件。它们不等同旧 `1p/2s/3a/3b`，也不代表成交建议或次级别确认。

OHLC沿用现有前复权口径，量额不另行缩放。缺少成交量保留 null，从该根起停用依赖量能的B1/S1；官方对象要求的数值占位不作为真实零成交展示，B2/S2和B3/S3继续计算。负数或非有限量额为 invalid_data。缺少成交额保留 null；当前选定信号不使用成交额。

## 时间和事件

- 输入是北京时间墙钟，严格递增、无重复。已闭合K才进入内核；未知闭合状态也不能确认结构。空闭合序列直接返回，不用空数组构造原生引擎。
- `chanlun_as_of` 在计算前截断；盘中回看不能看到当日收盘日线，未结束周/月不能提前确认。
- `structureDate` 为组成K真实极值日期；`availableDate` 为逐根观察首次命中时间，日/周/月采用 `period_end` 实际结束交易日，分钟保留时分。笔另外记录 `observedAt` 和官方 `finished_bis` 首次完成时间。
- 同规则、参数、笔端点持续满足只生成一次；同一当前笔条件消失或笔端点被撤回，记录 `structure_replaced`。窗口移到新笔时不删除历史事件。
- 价格失效为**本项目规则**：触及信号原K的低点（买）/高点（卖）即 `price_boundary`，不是官方止损规则。未闭合K只可触发价格失效。
- 失效后保留记录；持续命中不会重复生成，条件退出再进入才生成新事件。
- 图表标记按可知时间定位；周/月通过周期结束日期映射回所属K线。笔按实际端点绘制，未完成笔为虚线。

## API、缓存和兼容

保留 `/api/kline/daily`、`/api/kline/period` 与 `include_chanlun`、`chanlun_source`、`chanlun_as_of`。未启用分析不加载内核，不改变普通行情响应。

- `ruleVersion=4`；引擎元数据包含 name/version/commit/runtime/config，能力元数据含支持来源与信号规则。
- 唯一支持来源是 stroke；兼容接收 segment，但返回 status=unsupported 和空结构，禁止静默替代。
- 内核加载失败或版本不符为 engine_unavailable；计算异常为 invalid_data，不缓存失败，也不破坏普通行情接口。
- 后端最多缓存16份不可变结果，键含完整OHLCV/成交额、时间和闭合状态、周期、来源、观察截止、引擎版本及参数，返回独立副本。原生实例只在一次计算内使用。
- 前端查询键加入契约版本4与 `chart-rules-v1`，继续隔离资产、标的、周期、窗口和刷新版本；缺少 `chartRulesVersion=1` 的旧线段/背驰覆盖层选项不自动启用新规则，读取时不写配置，新选择由用户操作保存。
- AI快照同步提供能力和规则元数据，不将空旧字段解释为“未发现背驰”。多周期仅作只读对照。

## 结构分析首块概览

右侧“缠论结构”首块展示周线、日线、30分钟三张卡片，打开该标签时才加载其他周期，当前图表周期复用已有查询。卡片选择联动概览选中态、近期收盘迷你图及下方“走势分析 / 下一步观察”，不改变主图周期。

走势名称直接映射后端 `trendType`；阶段优先展示后端 `interpretation.phase`，与流程图一致，旧响应缺少该字段时才映射最新中枢的 `state`。多级标题按相邻周期方向组合为推进、整理、回落或反弹，仅为展示近似，不补算笔、中枢或递归结构。中间周期缺失时不跨级比较。

信号摘要按首次可知时间统计：周线近30个自然日、日线近7个自然日、30分钟当日（均含观察日）；最近候选及失效事件均可显示，失效会明确标记。查询继承历史截止时刻，不使用计算机当天时间；历史窗口不足时只说明当前窗口。加载、失败、空数据和指数30分钟不支持分别显示。隐藏日期时同步隐藏信号日期。

## 走势分析与下一步观察

布局参考 chanL 的阶段图、本级/相邻级别观察和价位梯。后端新增可选 `interpretation`（version=1、ruleSource=project），由现有官方笔、中枢和已闭合K线生成展示解读，不更改 `trendType` 或官方辅助信号规则。前端只展示该字段，旧响应缺少解读时明确提示重新计算。查询键增加 `interpretation-v1` 隔离旧缓存；AI快照包含阶段、事实及观察条件。

阶段：收盘位于中枢核心区间外为“离开中枢”；形成后曾有闭合收盘位于区间外、当前回到区间内为“回到中枢”；其余按三笔形成/三笔以上延伸展示。仅已闭合K线可推进阶段，未闭合尾K不会产生阶段确认。图上的MACD背驰观察不直接确认严格背驰阶段，不恢复旧背驰引擎。中枢边界相等仍有效，价位梯以现价为距离基准，不计算中枢宽度比例。

公式 a＋中枢＋b 只示意最新中枢及其前后真实笔，缺失进入笔和待形成后续笔明确标记，不冒充递归走势段。阶段图的箭头表示可能的观察分支，不是预测路径。相邻周期采用现有周/日/30分钟结果作只读对照，低于30分钟或高于周线的未接入级别不补造数据，次级别联立确认仍不可用。

走势分析只列观察截止时仍有效的 CZSC 辅助事件，按首次可知时间倒序；可展开规则、原始输出、首次可知/极值时间、对应笔完成情况及项目失效边界。下一步观察列出中枢边界、离开后的回抽条件，以及三周期中枢/所选周期信号价位梯。失效信号不进入有效清单，历史回看只按当时状态判断。

## 线段、趋势、背驰观察与中枢延长线

- **线段**：`segments` 的 `ruleSource=project`、`rule=feature-sequence-v1`。最少三笔且初始三笔有重叠；反向笔构成特征序列，按当前段方向处理包含关系。无缺口特征分型可确认端点；有缺口时再等待反向特征分型。未完成笔不参与特征确认，末段保留为虚线。逐根重放时记录真实首次 `observedAt` / `confirmedAt`，不把确认时间回填成端点时间。线段显示为蓝色粗线，不替换官方笔，也不作为 `chanlun_source=segment` 的中枢分析源。
- **趋势**：`trends` 由相邻笔中枢核心区间关系分组，保持与现有 `trendType` 相同的上下移口径。反向或重叠关系切换时开启新组；云带连接实际中枢上下沿，红色上行、绿色下行、琥珀色盘整。当前组延伸到最后已闭合K线，标为“当前”，边缘虚线；`ruleSource=project`，属于中枢位置近似，非官方递归走势确认。
- **背驰观察**：`divergences` 新记录采用 `kind=macd`、`ruleSource=czsc`，调用官方 [`tas_macd_bc_V230804(di=1)`](https://github.com/waditu/czsc/blob/v1.0.2/crates/czsc-signals/src/tas.rs#L4560)，其MACD参数固定12/26/9。官方规则在最近七笔范围内检查中枢与同向分型DIF强弱。逐根记录首次命中、原始key/value、两个比较端点、对应笔完成情况；同一笔持续命中不重复，当前笔条件消失或端点被撤回时记录失效，切换检查新笔不抹除历史。菱形标记放在首次可知位置，虚线连接原比较端点，失效记录灰色保留。它不是旧MACD面积背驰，也不自动成为B/S信号或严格趋势背驰。未闭合K不会创建或确认背驰观察。
- **中枢延长线**：`centerExtensions` 沿官方中枢固定的ZG/ZD，从中枢末端延长到最后已闭合K线；不投射未来价格，最新中枢边界有中文标签。零宽中枢只绘制一条参考线。延长线可独立开关，无须开启中枢矩形。

四个新图层默认关闭，菜单按后端能力开放。前端只投影后端坐标；新线段和背驰图层拒绝使用没有规则来源的旧结果。密集视图中失效背驰保留菱形和悬停详情、隐藏文字；窗口外标记不挤入可见区。AI快照同步携带线段和背驰来源、规则、首次可知时间及当前趋势组，避免把项目推导当成官方原生输出。

线段只复用确认所依赖笔序列完全未变的历史前缀；端点或笔完成状态被撤回时，从受影响位置重算。完整重算与重放结果在测试中交叉核对。5000根合成K线在运行开发服务的本机上冷算约35.81秒、缓存命中约0.091秒；500/2000根分别约0.998/6.774秒。该记录不与早期基准作严格性能比较。缠论查询使用现有300秒计算超时，普通行情查询仍为30秒；长窗口首次计算仍可能等待，不适合直接按标的在行情回调内批量重放。

## 条件推演

参考 chanL 探索里的条件分支，采用后端 `chanlun_projection.py` 对现有 CZSC 笔中枢生成 `projection`（version=1、ruleSource=project）。这是 L3 核心扩展，复用当前行情、历史截止和分析缓存，不增加模型调用或独立行情请求。`engine.config.chartRules.projectionVersion=1` 和前端查询键 `projection-v1` 隔离旧结果；旧后端缺少能力时禁用入口。未增加用户配置或数据迁移。

“推演”开关位于 K 线工具栏，默认关闭，按当前标的及周期启用，与其他缠论覆盖层独立。右侧留出条件示意区，绘制三条虚线路径和编号；点击路径编号或图下分支按钮可查看条件、含义及最近上下方历史中枢。无中枢、旧响应和计算错误明确显示状态。主图过低时提示增高，文字与按钮在窄屏换行。价格保持股票/ETF精度。

- **中枢内**：向上离开、向下离开、继续震荡。
- **中枢上方**：回抽未回、回到中枢、新高力度观察。
- **中枢下方**：回到中枢、反弹未回、新低力度观察。

区间仅取观察位置之前已经形成的官方笔中枢；中枢上下沿相等仍有效。力度分支按已确认口径核对官方 `tas_macd_bc_V230804(di=1)`，不恢复 chanL 的旧 MACD 柱面积条件。分支是尚待满足的观察条件，突破边界不等于确认 B3/S3，MACD观察不等于严格背驰或反转。

锚点使用最后已闭合K线收盘价，`anchor.availableDate` 使用实际周期结束交易日；开放尾K不能推进推演。开启历史推演时，图表展示截断至后端锚点，关闭后恢复原始行情视图，输入数据保持只读。所有图层点仍锚定真实K线，右侧横向距离与分支终点采用示意布局，不创建未来K线、未来日期、目标价或概率。推演区遮住图表库自动外推的日期刻度，关闭十字线日期浮签，保留真实历史日期轴和OHLC日期。AI快照包含相同规则来源与说明，不能将示意路径当成预测结果。
