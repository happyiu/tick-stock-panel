# 日 K 图表维护

基础迁移起点为 `dev` 的 `d1b8f4a`；缠论与调试迁移基线为 `6db7f0e`，保留现有业务能力。
基础 K 图表使用固定版本 `klinecharts@10.1.0`。入口为
`frontend/src/components/KLineCandlestick.tsx`，由 `StockDailyKChart` 和指数页复用；
自选详情与回测弹窗通过 `StockPanel` 接入；独立个股分析页的 `AnalysisKChart` 也复用该入口。
单日/多日分时与列表迷你图仍使用各自现有实现。

当前基础蜡烛、MA/BOLL、VOL/MACD/RSI/KDJ，以及天使魔鬼、boll2、KD背离/增强版、ETF波段、多空趋势使用新引擎。
缠论覆盖层和隐藏日期调试也使用同一个 KLineChart 实例，切换不再更换引擎。
`EChartsCandlestick` 文件仅保留历史导入路径兼容导出，不包含 ECharts 绘图实现。
30分钟/日/周/月周期、ETF三位价格精度、策略/信号选择和本地指标设置均保留。

## 数据与指标

- 沿用现有 API、React Query 查询键、SSE 和 `daily/latest` 缓存合并，不由图表另建网络订阅。
- `lib/kline-chart.ts` 将日期或30分钟墙钟时间按北京时间转为毫秒时间戳，将 `amount` 映射为 `turnover`，不转换成交量单位。
- MA、MACD、RSI、KDJ、BOLL 使用 `TSP_*` 自定义指标投影后端计算列；不能直接替换为同名内置指标，参数、历史预热和 BOLL 标准差口径可能不同。
- VOL5/VOL10 包含当天；量能倍数为当前成交量除以前 N 个交易日均量，不包含当天，零分母和历史不足显示缺失。
- 同日末根变化与新增一日通过 `setDataLoader.subscribeBar` 的回调更新；历史修订和窗口变化使用 `resetData`，保留浏览位置。切股重置视图和悬停。
- 当前只显示调用方请求的日期窗口，`getBars` 返回 `more=false`，不额外向边界分页取数。

MA 均线位于“自编 → 主图叠加”，默认勾选；通过 `stockPreviewMaVisible` 独立保存开关，兼容旧主图设置中没有 MA 的情况。图线与信息栏数值同时显隐，天使魔鬼仍优先替换普通均线，移除天使魔鬼后按 MA 开关恢复。

## 内置指标与手动画线

指标菜单先按“自编 / 内置”筛选，每次打开默认“自编”；两类均保留主图/副图分类与原有选择存储，切换分类不修改已启用指标。`lib/kline-chart-builtins.ts` 增加20个原生指标：
主图 EMA、SMA、BBI、SAR；副图 BIAS、BRAR、CCI、DMI、CR、PSY、DMA、TRIX、OBV、VR、WR、MTM、EMV、AO、ROC、PVT。
使用 `builtin-*` 选择键与库内公式名，保持原有 `TSP_*` 计算不变；新增指标只在启用时计算，使用库默认参数，不参与后端技术评分。
AVP 暂不开放：当前前复权价格、原始成交额与按手存储的成交量不能直接相除得到同口径均价。

共享图表上的画线工具栏提供趋势线、水平线/射线、直线、垂直线、平行线/价格通道、斐波那契与自由画笔。
可吸附K线、锁定/解锁全部手动画线、删除选中线、清空当前上下文；Esc取消未完成绘制。
完成绘制与拖动修改后通过 `storage.chartDrawings(symbol, period)` 保存到当前浏览器；只恢复工具名、时间戳、价格坐标与锁定状态，不保存回调或系统覆盖物。
手动画线使用独立 `tsp-user-drawings` 分组，删除/清空不影响缠论、策略信号和关键价位；切股/切周期移除旧图形并恢复对应记录，隐藏日期调试不恢复手动画线。
图表本身不增加行情请求。升级需核对覆盖物回调顺序、吸附模式、原生指标名及按时间戳恢复行为。

## 自定义公式

`lib/kline-chart-formulas.ts` 注册六个 `TSP_*` 指标，直接复用现有 `calculate*` 函数。
天使魔鬼替换默认MA，并保留空心红色多头、实心青色空头及原价格坐标上的进攻/撤退标记；boll2保留延后一根的通道。
四个副图使用原生曲线和箭头，自定义绘制参考线、KD背离连线、STICKLINE及信号文字；柱线保留上下端和按柱间距计算的宽度。
多空趋势接收显式周期，切换周期时触发重算；纵轴保留小于0、大于100的数值，防守价/趋势价只出现在提示中。
缺失成交量通过 `source_volume` 保留，不能被原生量柱使用的零值替代；不改动公式预热、确认延迟或信号冷却。
副图提示随十字线更新并自动换行；窄屏预留更多顶部空间。密集信号文字按可见区域避让，不显示边缘被截断的半个标签。

KLineChart 副图上方分隔线支持上下拖动。拖动后通过统一 `storage.stockPreviewSubChartHeights` 保存各副图的绘图区高度，切换周期、主题、指标排序、关闭重开或刷新页面时保持；窄屏换行仅增加提示区高度，不重置绘图区。主图保留至少120px，副图绘图区保留至少50px。日期轴固定在主图与副图之间，隐藏日期调试时不显示日期文字。

## 缠论、调试与独立分析页

`lib/kline-chart-chanlun.ts` 将已有 `ChanlunAnalysis` 投影为分型、笔、线段代理、中枢、候选买卖点与背驰代理覆盖物，不重算分析。笔和线段按确认状态区分虚实线；候选买卖点按 `availableDate` 定位，等待状态不显示为候选。悬停说明保留结构发生、最早可知、失效边界及证据；隐藏日期时同时隐藏信息栏、日期轴、十字线和缠论说明中的日期。

独立 `/stock-analysis` 页的关键价位图保留分组开关、枢轴档位、压力支撑与曲线双向高亮。`lib/kline-chart-levels.ts` 绘制水平价位、布林/Keltner/ATR 后端序列，按日期对齐，缺失处不连线；右侧预留标签空间，范围条通过公开 API 控制与同步缩放。不恢复 `d1b8f4a` 已移除的自选详情关键价位功能。

## 业务交互

自选详情使用与关键价位分析一致的卡片边框、内边距、轻量工具按钮和范围条，默认可见120根K线。OHLC/均线信息、指标选择及副图高度设置继续保留。容器尺寸改变时，等待原生画布布局完成后再适配默认视野；用户已经手动缩放或拖动时保持原有浏览位置。

`lib/kline-chart-overlays.ts` 管理程序生成的买卖/涨停/炸板、自选日、区间和价格线覆盖物。
业务覆盖物锁定位置并阻止右键删除；涨停标签在可见根数大于 60 时简化为圆点，买卖箭头保留。
预警价格参与主图纵轴范围。蜡烛点击回传日期，主图双击经公开坐标转换 API 回传价格；副图双击不触发价格预警。

## 指标管理

侧栏“指标”页面保留“内置 / 自建”和“主图叠加 / 副图”分类。内置指标只读；自建支持源码查看、新建、编辑、复制和删除。自编指标（含反转拐点）归为自建，初始定义位于后端 `app/indicators/chart_defaults/`，公式为可编辑的通达信风格语法。

用户修改保存在当前数据目录的 `user_data/custom_indicators/`，不修改仓库中的初始定义。稳定ID与版本号用于并发校验；删除记录持久化为标记，重启不会恢复已删除指标。损坏定义单独报错并停止加载，不退回初始公式伪装成功。

- 管理API：`GET/POST /api/indicators`，`GET/PUT/DELETE /api/indicators/{id}`；修改和删除携带当前 `revision`。复制通过 `copy_from` 保留绘图高度、精度和历史起算口径。
- 校验与语法说明：`POST /api/indicators/validate`、`GET /api/indicators/language`。
- 日线/周期K线支持 `indicator_ids`（逗号分隔）与 `indicator_compare_days`，一次返回全部已启用自建指标的 `indicator_results` 与独立错误。已有标准化数据的指数、关键价位图通过 `POST /api/indicators/evaluate` 使用同一计算器。
- 新K线请求包含指标版本和参数；结果按日期对齐。管理操作只失效指标目录和图表查询，不清空策略、监控、回测缓存或重写行情数据。
- 详情页统一持有指标选择，信息条、K线和邻股预取共用包含指标版本的查询键；首次等待目录就绪，避免先请求无指标行情再重复请求。
- 图表结果只传显式输出、绘图参数及既有提示/蜡烛着色字段；常量参数存于 `drawings[].constants`，重复数值列合并引用。前端同时兼容原逐根参数与常量参数，上下文只保留一份按日期索引的数值；未变化指标不重复覆盖，成交量提示只读取当前K线。

示例：

```text
快线:MA(CLOSE,5),COLORYELLOW;
慢线:MA(CLOSE,20),COLORCYAN;
买点:=CROSS(快线,慢线);
DRAWICON(买点,LOW,1),COLORRED;
DRAWTEXT(买点,LOW*0.98,'金叉'),COLORRED;
```

此实现是受限公式解释器，不执行Python/JavaScript代码，也不承诺完整通达信兼容。编辑器的函数说明是当前支持清单；不支持的函数、未来引用、非法参数均报错。每个公式最多32768字符、256条语句、64层表达式；单次最多20000根K线，同时受运算量、结果规模与计算时间限制。

曲线输出支持 `POINTDOT`：每根有效K线的数值绘制为独立实心圆点，不连接相邻点；`LINETHICK1～5` 决定点的直径（像素），颜色和 `NODRAW` 沿用原有规则。例如 `上轴:1,COLORGRAY,POINTDOT;`。普通实线和 `DOTLINE/DOTLINE2` 虚线保持原样。

### 反转拐点（主图源码）

在“指标 → 自建 → 主图叠加”查看、编辑或复制“反转拐点”，然后在股票/ETF详情的主图指标菜单中启用：

```text
{ 跟随当前K线周期；左3根、右2根，右侧K线收盘后确认 }
左侧:=3; 右侧:=2;
DRAWPIVOT(HIGH,左侧,右侧,1),COLORRED;
DRAWPIVOT(LOW,左侧,右侧,-1),COLORGREEN;
```

`DRAWPIVOT(价格序列,左根数,右根数,方向)` 是本系统新增的绘图指令，不是完整通达信或 Pine 兼容接口。左右根数为正的固定整数，窗口合计最多20000根；方向 `1` 为压力、`-1` 为支撑，通常分别传 `HIGH`、`LOW`。可修改颜色、`LIGHTCOLOR`、线宽、虚线，或通过 `NODRAW` 隐藏该方向。

- 按当前日/周/月/30分钟K计算；候选必须优于右侧所有价格，允许与左侧极值相等，因此平台取最近的等高/等低位置。整个确认窗口必须有有效价格且已收盘，线从确认K线开始，不补画到拐点当日。
- 最高价严格高于压力或最低价严格低于支撑时整条移除，包含盘中已经发生的突破；相等触碰不移除。同方向同价有效线去重，突破后允许再次形成。
- 复用K线的 `is_closed`；未提供状态时，历史根视为已收盘，末根保守视为未收盘。缺少对应最高/最低价时清除该方向已有线，避免将无法验证的价位视为有效。
- 只显示截至数据末端仍有效的最近500条线，不因缩放和可见区变化而重算；从历史窗口之前确认的线可延续进入当前画面。没有加载的更早历史不能生成价位；切换数据范围可能引入更多历史价位。
- API的 `drawings[].levels` 为可选字段，每条含 `value`、`pivot_date`、`confirmed_date`，使用所属周期的日期标签；旧绘图响应保持兼容。收盘状态进入计算快照和缓存键，不重写行情或 enriched 数据。

此功能仅用于主图参考，不提供通知和交易信号。最终剩余线会随后续突破消失，不能将它们倒推为历史可用的买卖信号。形态参考 [Reversal Pivot Points](https://github.com/razorbladekisses/Tradingview-Indicators/blob/main/indicators/Reversal%20Pivot%20Points)，计算与绘制按上述规则独立实现，未复制其 Pine 源码。

“个股/ETF详情 → 关键价位”和个股分析页也提供独立的“反转拐点”开关，沿用关键价位的日K及历史截止日期口径，固定左3右2，复用同一公式计算器。返回的 `levels.reversal_pivot` 含有效价位、支撑/压力方向、拐点日和确认日；图上从确认日开始延续，明细显示价格和距现价幅度。拐点不强制撑大价格轴，远端价位仍保留在明细中。开关默认关闭，旧响应或旧报告缺少该组时按空组处理。此入口使用固定参数，不跟随用户在主图源码中的编辑。

### 供需区域（关键价位）

“关键价位 → 供需区域”默认关闭，按日K及当前历史截止日期计算。供给区用半透明红色、需求区用半透明绿色矩形展示，从第二根确认K线向右延续；区域不强制扩大价格轴，远端区域仍列在右侧明细中。

- 前一根阳线、当前阴线，当前实体至少为前一根的1.8倍，且当前开盘不低于前一根开盘、当前收盘不高于前一根收盘，形成供给区。下沿为前一根开盘价，上沿为两根最高价的较大值。
- 前一根阴线、当前阳线，当前实体至少为前一根的1.8倍，且当前开盘不高于前一根开盘、当前收盘不低于前一根收盘，形成需求区。下沿为两根最低价的较小值，上沿为前一根开盘价。
- 两根K线均须已收盘；零实体、缺失或非法OHLC不生成区域。复用反转拐点的北京时间收盘状态处理。盘中最高价严格超过供给区上沿、最低价严格跌破需求区下沿时整块移除，仅进入区域或触碰边界保留。缺少最高/最低价时清除无法验证的有效区域。
- 同方向、相同上下沿去重；允许多个及重叠区域共存，最多保留最近确认的500个。API新增 `levels.supply_demand`，包含 `lower`、`upper`、`formed_date`、`confirmed_date`，`value`为区间中点用于兼容排序；展示和摘要使用上下沿，明细幅度按距最近边界计算，区域内为0%。旧响应缺少分组时按空组处理。

形态参考 [Institutional Supply & Demand Zones](https://github.com/razorbladekisses/Tradingview-Indicators/blob/main/indicators/Institutional%20Supply%20%26%20Demand%20Zones)，按上述规则独立实现，未复制Pine源码。这里只使用价格形态，不代表真实机构订单；首版不做跨周期叠加、通知和交易信号。

原有六个复杂公式保留“已加载K线序列”的历史起点（并非画布可见区），缩放/拖动不触发重算；复制保留这一口径。MA/MACD/RSI/KDJ/BOLL初始公式复用同口径的后端预热列；改变公式后使用请求提供的历史计算，先计算后裁剪。前端通用图表组件的旧props调用仍保持兼容，应用页面传入管理目录与后端结果后使用新路径。选股、评分、监控和回测的指标流水线不受管理页修改影响。
